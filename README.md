# Power Grid Management System

Система управления ремонтами и техническим обслуживанием энергосетей.

## 🚀 Технологии

- Java 11+
- Hibernate ORM
- MySQL
- JSP/JSTL
- Maven
- Jetty Server

## 📋 Функциональность

- Управление пользователями и ролями
- Планирование ремонтов
- Формирование отчетов
- Админ-панель
- Аутентификация и авторизация

## 🗄️ База данных

База данных уже настроена и содержит:
- 1 объединение (ГПО "Белэнерго")
- 6 предприятий (РУП-облэнерго)
- 25 филиалов
- Планы на 2025 год
- Пользователей и роли
